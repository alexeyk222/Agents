# Engineering & Simulation

**Назначение**: физические, инженерные и дискретно-событийные вычисления.

| Skill | Когда использовать |
|---|---|
| `sympy` | Символьная математика и аналитические выражения |
| `simpy` | Discrete-event simulation |
| `fluidsim` | Computational fluid dynamics |
| `openpiv` | Particle image velocimetry |
| `matlab` | MATLAB analysis и scripts |
| `lab-hardware-cad` | CAD для лабораторного оборудования |

`lab-hardware-cad` создаёт локальные проекты; изготовление или управление
оборудованием относится к режиму `hardware` и требует отдельного подтверждения.
