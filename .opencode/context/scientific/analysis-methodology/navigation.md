# Analysis & Methodology

**Назначение**: дизайн исследования, статистика, гипотезы, review и научное письмо.

| Группа | Skills |
|---|---|
| Study planning | `experimental-design`, `statistical-power` |
| Data understanding | `exploratory-data-analysis`, `statistical-analysis` |
| Hypotheses | `hypothesis-generation`, `hypogenic`, `scientific-brainstorming` |
| Critical review | `scientific-critical-thinking`, `peer-review` |
| Evidence synthesis | `literature-review` |
| Outputs | `scientific-writing`, `scientific-visualization` |

`literature-review` требует review при загрузке. Для анализа уже собранных
данных не применять `experimental-design` вместо статистического workflow.
