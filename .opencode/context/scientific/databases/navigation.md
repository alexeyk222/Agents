# Scientific Databases

**Назначение**: поиск и получение актуальных научных данных. Сетевые запросы
относятся к режиму `network-read`.

| Skill | Когда использовать |
|---|---|
| `database-lookup` | Унифицированный доступ к публичным базам |
| `depmap` | Cancer dependencies и cell lines |
| `imaging-data-commons` | Публичные cancer imaging datasets |
| `primekg` | Precision Medicine Knowledge Graph |
| `ncats-arax` | Biomedical Translator / ARAX graph |
| `usfiscaldata` | Данные U.S. Treasury |
| `ontology-term-resolution` | Нормализация ontology terms и CURIE |
| `pathogen-variant-surveillance` | Актуальный genomic surveillance |
| `hugging-science` | Scientific datasets и models на Hugging Face |

Skill roots: `.opencode/skills/<skill-name>/`.
