# Cheminformatics & Drug Discovery

**Назначение**: молекулярные представления, descriptors, screening, docking и
drug discovery ML.

| Skill | Основной маршрут |
|---|---|
| `rdkit` | Базовая cheminformatics и molecular I/O |
| `datamol` | Удобные RDKit workflows и стандартизация |
| `medchem` | Medicinal chemistry filters и analysis |
| `molfeat` | Molecular featurization |
| `deepchem` | ML для chemistry и biology |
| `pytdc` | Therapeutics Data Commons |
| `torchdrug` | Graph ML для molecules/proteins |
| `diffdock` | Molecular docking |
| `rowan` | Managed computational chemistry |

Для составного workflow сначала выбрать предметный skill, затем ML или
visualization skill только при необходимости.
