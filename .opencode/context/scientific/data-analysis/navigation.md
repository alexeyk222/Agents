# Data Analysis & Visualization

**Назначение**: табличные и распределённые вычисления, графы, геоданные,
визуализация и работа с единицами.

| Skill | Когда использовать |
|---|---|
| `polars` | Быстрые DataFrame workflows |
| `dask` | Распределённые и out-of-core вычисления |
| `vaex` | Очень большие табличные datasets |
| `geopandas` | Векторные геоданные |
| `geomaster` | Geospatial AI workflow; review required |
| `networkx` | Графы и network analysis |
| `matplotlib` | Базовая scientific plotting |
| `seaborn` | Статистическая визуализация |
| `uncertainty-and-units` | Units, propagation и uncertainty budgets |
