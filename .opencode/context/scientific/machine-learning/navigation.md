# Machine Learning & Deep Learning

**Назначение**: классический ML, probabilistic models, time series, graph ML,
reinforcement learning и quantum computing.

| Группа | Skills |
|---|---|
| Classical ML | `scikit-learn`, `shap`, `umap-learn` |
| Statistics / Bayesian | `statsmodels`, `pymc`, `scikit-survival` |
| Deep learning | `pytorch-lightning`, `transformers`, `torch-geometric`, `torchdrug` |
| Time series | `aeon`, `timesfm-forecasting` |
| Reinforcement learning | `stable-baselines3`, `pufferlib` |
| Optimization | `pymoo` |
| Quantum | `cirq`, `pennylane`, `qiskit`, `qutip` |

Не объединять несовместимые package stacks в одном окружении; зависимости
разрешать отдельно для выбранного skill.
