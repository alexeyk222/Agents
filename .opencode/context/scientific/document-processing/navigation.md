# Document Processing & Conversion

**Назначение**: чтение, создание, проверка и преобразование документов.

| Skill | Форматы |
|---|---|
| `docx` | Word / OOXML |
| `xlsx` | Excel / OOXML; review required |
| `pptx` | PowerPoint / OOXML |
| `pdf` | PDF, OCR, forms и conversion |
| `markitdown` | Документы в Markdown |
| `liteparse` | Structured document parsing |
| `markdown-mermaid-writing` | Markdown, Mermaid и templates |

Сохранять исходный файл; результат писать в новый output, если пользователь
явно не запросил изменение оригинала.
