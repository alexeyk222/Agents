# Шаблон: мэппинг атрибутов и паспорт витрины

**Назначение**: единый формат результата разведки данных, который агенты
заполняют на этапе 4 сценария `workflows/data-discovery.md`.

---

## 1. Паспорт объекта

| Поле | Значение |
|---|---|
| Объект | `db.table` |
| Задача | `PROJ-0000` (ссылка) |
| Владелец / команда | из `DESCRIBE FORMATTED` или Confluence |
| Гранулярность | одна строка = … (проверено запросом) |
| Партиционирование | ключ, глубина истории, размер |
| Периодичность загрузки | из Confluence / по партициям |
| Изученный период | `dt` с … по … |
| Документация | ссылки на страницы Confluence |

---

## 2. Мэппинг атрибутов

| # | Атрибут | Тип | Бизнес-термин | Определение (кратко) | Источник | Заполн., % | NDV | Аномалии | Статус |
|---|---|---|---|---|---|---|---|---|---|
| 1 | `operation_id` | STRING | ID операции | Уникальный ID в процессинге | [Паспорт](URL) | 100.0 | ≈ rows | дубли: 0 | ✅ подтверждён |
| 2 | `mcc_code` | STRING | MCC | Код категории торговой точки | [Справочник](URL) | 97.3 | 512 | `'0000'` 1.1% | ⚠️ расхождение |
| 3 | `…` | | | | — | | | | ❓ не найдено |

**Статусы**: ✅ подтверждён — определение найдено и согласуется с данными;
⚠️ расхождение — определение есть, данные ему противоречат;
❓ не найдено — определения нет ни в Confluence, ни в комментариях колонки.
